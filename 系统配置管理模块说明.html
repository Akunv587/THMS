系统配置管理模块

设备库存管理系统 (EquipmentIMS) 中负责全局参数集中管理的核心模块。
通过键值对 (Key-Value) 方式统一存储和分发系统级配置，实现业务逻辑与运行参数的解耦。

一、模块架构与定位

系统配置模块采用 分层架构，贯穿表现层 (Web)、业务逻辑层 (BLL) 和数据访问层 (DAL)：

1
SysConfig 实体
Models 层
数据库表映射

Web 层
分组映射 + 页面
4
Razor Views
前端
Index 预览 / Edit 编辑
Sys_Config 表

存储于 SQL Server 中，以 ConfigKey 为唯一标识的键值对

IMemoryCache 缓存

每个配置项独立缓存 30 分钟，首次读取后缓存在内存中

权限分级

sys:config:view 可查看 / sys:config:edit 可修改

分组展示

按业务域自动分组：公司信息 / 单据设置 / 安全策略 / 预警设置

二、数据模型 — Sys_Config 表

配置项实体 SysConfig 映射到数据库表 Sys_Config，结构如下：

字段类型说明

ConfigKeynvarchar(100)配置键（唯一标识），如 CompanyName

ConfigNamenvarchar(100)中文显示名称，如"公司名称"

ConfigTypetinyint (枚举)数据类型：1=字符串, 2=数字, 3=布尔, 4=JSON

ConfigKey 命名采用 PascalCase 规范，前缀体现所属业务域（如 DocPrefix_ 为单据前缀类）。

三、配置项分类体系与详解

系统将所有配置项按业务域划分为 4 大分组（外加兜底的"其他设置"），每组在页面上以 Bootstrap Icons 图标标识：

公司信息 4 项
ConfigKey名称类型默认值用途说明
CompanyName 公司名称 字符串 郑州恒锐自动化设备有限公司 企业全称，用于报表抬头、登录页面标题、系统各处显示的机构名称
CompanyAddress 公司地址 字符串 (空) 经营地址，用于采购单/销售单等正式单据的落款区域
CompanyPhone 联系方式 字符串 (空) 联系电话/传真，出现在对外单据的联系信息栏
CompanyEmail 电子邮箱 字符串 (空) 企业邮箱，用于系统通知发件人和对外联络信息显示
单据设置 5+ 项
ConfigKey名称类型默认值用途说明
Prefix_PurchaseOrder 采购订单前缀 字符串 PUR / CG 采购订单编号的前缀，如 PUR20260718001。与流水号拼接生成唯一单据号
Prefix_SaleOrder 销售订单前缀 字符串 SALE / XS 销售订单编号的前缀，用于快速区分单据类型
Prefix_PurchaseIn 采购入库前缀 字符串 (自定义) 采购入库单编号前缀
Prefix_SaleOut 销售出库前缀 字符串 (自定义) 销售出库单编号前缀
Prefix_RepairOrder 维修工单前缀 字符串 (自定义) 维修工单编号前缀
Prefix_Transfer 调拨单前缀 字符串 TRF / DB 库存调拨单编号前缀
安全策略 5 项
ConfigKey名称类型默认值用途说明
PasswordExpiryDays 密码过期天数 数字 90 用户密码的有效天数。设为 0 表示密码永不过期。到期后系统强制要求修改密码
MaxLoginAttempts 最大登录失败次数 数字 5 连续登录失败达到此次数后，账户将被临时锁定。用于防止暴力破解
LockoutMinutes 锁定时间（分钟） 数字 30 账户被锁定后的自动解锁等待时长。30 分钟后可重新尝试登录
PasswordHistoryCount 密码历史数量 数字 5 禁止重复使用的历史密码数量。修改密码时不能与最近 N 次密码相同
CreditCheckEnabled 信用额度检查开关 布尔 false (禁用) 是否启用客户信用额度检查。启用后超出信用额度的客户将无法继续赊销
预警设置 4 项
ConfigKey名称类型默认值用途说明
StockAlertCheckCron 库存预警检查时间 字符串 08:00 每日低库存预警的自动检查时间（格式 HH:mm）。后台定时服务在此时间扫描库存
MaintenanceReminderDays 保养提前提醒天数 数字 (自定义) 设备保养到期前 N 天开始发送提醒通知，确保维护工作及时执行
StockAlertLowQty 库存预警低阈值 数字 10 某设备库存数量低于此值时触发"低库存预警"，提示采购补货
StockAlertHighDays 库存积压天数 数字 90 库存存放天数超过此值时触发"库存积压预警"，提示促销或调拨处理

四、配置项数据类型

系统定义了 ConfigType 枚举（1~4），不同数据类型在页面上渲染为不同的表单控件：

String (1) — 字符串

单行文本

渲染为 <input type="text">。
用于公司名称、地址、单据前缀等

Number (2) — 数字

数字输入框

渲染为 <input type="number">。
用于阈值、天数、次数等整数参数

Boolean (3) — 布尔开关

Toggle 开关

渲染为 Bootstrap 风格 Switch 开关。
绿色="启用" / 灰色="禁用"

Json (4) — 复杂对象

多行文本框

渲染为 <textarea>。
用于需结构化存储的复杂配置

隐式类型转换： SystemConfigService.GetAsync<T>(key) 支持通过 System.Text.Json 将 ConfigValue 反序列化为任意 CLR 类型。例如，一个存为 JSON 字符串的配置项可以透明地反序列化为 C# 对象供业务层使用。

五、页面一：配置预览页（Index）

只读功能定位

  • 按配置分组（公司信息→单据设置→安全策略→预警设置）顺序展示
  • 每组以卡片形式呈现，头部显示图标 + 名称 + 项数
  • 表格列：配置键 → 名称 → 当前值 → 说明
  • 布尔值显示为绿色"启用"或灰色"禁用"标签
  • 空值显示为灰色 "(空)"
  • 顶部有"编辑配置"按钮（需 sys:config:edit 权限）

六、页面二：配置编辑页（Edit）

编辑功能定位

Edit 页面是配置的可编辑表单视图，采用 Bootstrap Accordion（手风琴）组件按分组折叠展示。需要 sys:config:edit 权限才能访问。

  • 使用 Accordion 手风琴组件，首组默认展开，其余折叠
  • 根据 ConfigType 自动渲染不同控件（文本框/数字框/开关/文本域）

  • 支持 AJAX 批量提交，保存后自动清除缓存并跳转预览页

表单提交机制

Edit 页面使用 AJAX 异步提交，通过 jQuery 序列化整个表单，利用 Dictionary<string, string> 接收所有配置键值对。控制器内部 __ 开头的键（如 AntiForgeryToken）会被自动过滤，然后逐键调用 SetAsync() 更新。提交完成后自动清除 SysConfig:* 前缀的缓存键。

七、缓存机制与性能优化

系统配置是典型的"读多写少"场景——运行期间频繁读取、极少修改。为提高性能，采用 ASP.NET Core IMemoryCache 实现本地内存缓存：

30 分钟过期

CacheDuration = 30min
每个键独立缓存，到期自动失效

键名隔离

缓存键格式 SysConfig:{key}
与其他缓存数据不冲突

写入即刷新

SetAsync 后立即更新对应缓存
不需要等待自然过期

批量清除

RemoveByPattern("SysConfig:")
编辑后一键清除所有配置缓存

缓存工作流程
1. 首次读取

业务代码调用 GetAsync("CompanyName") → 缓存未命中 → 查询 Sys_Config 表 → 写入 IMemoryCache → 返回

2. 30 分钟内再次读取

缓存命中 → 直接返回内存中的值，完全不访问数据库

3. 编辑保存

写入数据库 → 更新对应缓存 → 清除整个 SysConfig:* 命名空间 → 下次读取从 DB 重新加载

4. 30 分钟后自动过期

缓存条目被 GC 回收 → 下次读取重新查库并缓存

八、权限控制

只读sys:config:view

可访问 Index 预览页面

查看所有配置项的当前值

区分各分组和配置说明

无法进入 Edit 编辑页面

读写sys:config:edit

继承 view 权限的所有能力

可进入 Edit 编辑表单页

可修改所有可编辑配置项

保存后自动刷新缓存

实现方式

控制器类级别挂着 [PermissionFilter("sys:config:view")]，Edit 的 GET/POST Action 上额外挂着 [PermissionFilter("sys:config:edit")]。具有 edit 权限的角色同时也需要 view 权限，两者叠加形成"查看 → 编辑"的递进式权限体系。
